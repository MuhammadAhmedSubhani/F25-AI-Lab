# F25 AI Lab

This repository contains the assignment documents and Python examples for
five AI lab modules. Most tasks are provided as Word documents; Python
implementations are included for selected tasks.

### Python Examples

- [Lab 1, Task 2](./Lab%201/Task%202/Task%20-%202.py): checks whether a
  student passes based on marks, document completion, attendance, and
  assignment submission.
- [Lab 2, Task 3](./Lab%202/Task%203/Temp_controller.py): selects a
  temperature-control mode based on temperature and occupancy, and
  indicates whether a mode-change command is needed.
- [Lab 3, Task 1](./Lab%203/Task%201/TASK%201.py): demonstrates
  breadth-first search (BFS) and depth-first search (DFS) on a directed
  graph.
- [Lab 5, Task 2 — Minimax](./Lab%205/tASK%202/MiniMax.py): evaluates a
  binary game tree with the minimax algorithm.
- [Lab 5, Task 2 — Alpha-Beta Pruning](./Lab%205/tASK%202/Alpha%20Beta%20Pruning.py):
  evaluates a binary game tree using minimax with alpha-beta pruning.

The remaining tasks are currently represented by their `.docx` documents;
there are no Python scripts in those task folders.

## Requirements

- Python 3
- No third-party Python packages are required by the included scripts.
- Microsoft Word or a compatible document viewer is needed to open the
  `.docx` assignment documents.

## Running the Python Examples

Run a script from the repository root with Python. For example:

```bash
python "Lab 1/Task 2/Task - 2.py"
python "Lab 2/Task 3/Temp_controller.py"
python "Lab 3/Task 1/TASK 1.py"
python "Lab 5/tASK 2/MiniMax.py"
python "Lab 5/tASK 2/Alpha Beta Pruning.py"
```

The examples include test inputs or sample data and print their results to
the terminal. They do not require command-line arguments.
